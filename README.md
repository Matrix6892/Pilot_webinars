# КОЛЕР

Интерактивный демо-стенд агентного отдела продаж завода красок.

Посетитель пишет письмо-заказ, после чего система:

1. понимает потребность;
2. сверяет продукт, остаток и цену;
3. сопоставляет рыночный срез;
4. передаёт решение независимой модели;
5. выбирает зелёную, жёлтую или красную зону;
6. останавливается перед нестандартным обещанием и просит решение руководителя.

## Режимы

- **Автономный демо-режим** всегда работает на опубликованном сайте и
  демонстрирует три ветки на синтетических данных.
- **OpenCode live** включается локальным мостом. Запросы с сайта обрабатываются
  моделями подписки OpenCode Go на компьютере ведущего. Подписочные данные не
  переносятся в облако.

## Локальный запуск

```bash
npm install
npm run dev
npm run bridge
```

Локальные параметры моста задаются в `.env.local`:

```text
STAND_URL=http://127.0.0.1:3000
BRIDGE_TOKEN=...
OPENCODE_PRIMARY_MODEL=opencode-go/mimo-v2.5
OPENCODE_REVIEWER_MODEL=opencode-go/deepseek-v4-flash
```

## Источники

Рабочая демонстрационная Google-таблица содержит вкладки:

- `Товары`
- `Правила`
- `Рынок`
- `Отрасли`
- `Заказы`

В репозитории хранится синтетический снимок тех же данных, чтобы публичный стенд
не зависел от доступа к личному Google-аккаунту во время вебинара.
